# Breathing Orb

A minimal breathing widget made for my personal Notion page.

## Features

- Transparent / Notion-friendly background
- Gentle idle pulse and color changes throughout the day
- Multiple breathing modes
- Inhale, exhale, and hold guidance with countdowns
- Light and dark mode support
- Click the orb to start or pause
- Click `×` to return to idle

## How the color changes

The orb checks the browser's local time and gradually shifts between different color palettes during the day. It also has a slow ambient color drift while idle.

## Hosting

The widget is hosted with GitHub Pages at:

`https://ngthanhlt.github.io/breathing-orb/`

To update it, replace `index.html` in the `breathing-orb` repository and commit the change.

If Notion shows an older version, change the embed URL slightly, for example:

`https://ngthanhlt.github.io/breathing-orb/?v=2`
